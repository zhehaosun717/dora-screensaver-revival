# ドラえもんスクリーンセーバー復活計画

[English](README.md) | [中文](README.zh.md) | **日本語**

2000 年代、ドラえもんの公式サイト（ドラえもんチャンネル、映画ドラえもん公式サイトなど）では、Flash で作られたスクリーンセーバーが無料で配布されていました。Flash のサポート終了後、これらは今の Windows では動かなくなっています。`flash.ocx` が見つからないというエラーが出るうえ、日本語以外の環境では名前も文字化けします。

このプロジェクトは、それらを Windows 10 / 11 でもう一度動かします。

- オープンソースの Flash エミュレーター [Ruffle](https://ruffle.rs) で当時のアニメーションを再生します。**Flash Player のインストールは不要です。**
- ワイド画面に対応しています。4:3 のまま表示するほか、画面を広げる、画面いっぱいに拡大する、引き伸ばすから選べます。
- スクリーンセーバー名は日本語・中国語・英語の 3 種類から選べます。「設定」画面も名前と同じ言語で表示されます。
- **このリポジトリとインストーラーには、ドラえもんの素材は一切含まれていません。** インストール時に、インターネット・アーカイブ（Wayback Machine）から公式サイトが当時配布していた元ファイルをダウンロードし、お使いのパソコン上でアニメーションを取り出します。

## インストール

1. [Releases](https://github.com/zhehaosun717/dora-screensaver-revival/releases/latest) から `DoraSaverSetup.exe`（約 10 MB）をダウンロードします。
2. ダブルクリックで実行します。コード署名がないため「Windows によって PC が保護されました」と表示されることがあります。その場合は「詳細情報」→「実行」を選んでください。スクリーンセーバーを `C:\Windows\System32` に入れるため、管理者の確認（UAC）も表示されます。
3. 入れたいスクリーンセーバーと名前の言語を選び、「インストール」を押します。1 つずつダウンロード・検証・取り出しを行い、通常は 1 分以内に終わります。
4. 「スクリーンセーバーの設定を開く」を押して、一覧から選べば完了です。

**動作環境**：Windows 10（1903 以降）または Windows 11。インターネット接続が必要です。ランタイムを別に入れる必要はありません。.NET Framework 4.8 は Windows に標準で入っています。Microsoft Edge WebView2 ランタイムも Windows 11 には標準で入っており、ない場合はインストーラーがマイクロソフトの公式サイトから自動で入れます。

**コマンドラインでのサイレントインストール**（まとめて配布したい場合など）：

```bat
DoraSaverSetup.exe /install /quiet /names=ja
DoraSaverSetup.exe /uninstall /quiet
```

オプション：`/names=ja,zh,en` でどの言語の名前を入れるか選べます。`/savers=birthday,dch2` で特定のスクリーンセーバーだけを入れられます。`/lang=ja|zh|en` はログの言語です。終了コードは、成功が 0、一部だけ成功が 1、失敗が 2 です。

## 使い方

- 「スクリーン セーバーの設定」で選んだあと、「設定」を押すと次のことができます。
  - 効果音・BGM のオン／オフ（初期状態はオフ）
  - ワイド画面での表示方法：4:3 のまま、画面を広げる、画面いっぱいに拡大（上下を切り取り）、引き伸ばし。スクリーンセーバーごとにおすすめの初期値があります。
- マウスを動かす、クリックする、キーを押すと終了します。
- ディスプレイが複数ある場合は、すべてのディスプレイでアニメーションを再生します（音はメインのみ）。「設定」でメインのディスプレイだけにすることもできます。

## アンインストール

「設定 → アプリ → インストールされているアプリ」から「Doraemon Screensaver Revival」をアンインストールするか、`DoraSaverSetup.exe` をもう一度実行して「アンインストール」を押してください。

以前の動かなくなった旧版がパソコンに残っていた場合、インストール時に `C:\ProgramData\DoraSaver\original-backup` へ移動します。削除はしません。

## しくみと安全性

- 元ファイルごとに、インターネット・アーカイブ上の保存場所と SHA-256 ハッシュを固定しています。ダウンロードした内容が一致しなければ使いません。
- **当時のインストーラーは一切実行しません。** 元ファイルは圧縮ファイルとして読み取るだけです。zip は .NET の標準機能、LHa は Windows 標準の `tar.exe` で展開します。2001 年版の RAR 2.0 形式とパーマンの StuffIt 形式に限り、オープンソースのツール [unar](https://theunarchiver.com/command-line) を追加でダウンロードします（これも SHA-256 で検証します）。そのうえで、長さと SHA-256 が記録と完全に一致する Flash アニメーションだけを取り出します。
- スクリーンセーバーは WebView2 上の Ruffle で再生され、パソコン内のアニメーションファイル以外にはアクセスできません。外部への通信やページ移動はすべて遮断しています。

## ソースからビルドする

.NET SDK 8 以降が必要です。

```powershell
./build.ps1
```

ビルドスクリプトは、バージョンを固定した Ruffle をダウンロードして SHA-256 を確認し、テストを実行してから各スクリーンセーバーをビルドし、最後に `dist\DoraSaverSetup.exe` を作ります。
