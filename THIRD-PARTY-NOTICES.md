## Downloaded at install time (not redistributed)

### The Unarchiver command-line tools (`unar`)
Only fetched when a screensaver whose original is a RAR 2.0 or StuffIt archive is selected,
from https://cdn.theunarchiver.com/downloads/unarWindows.zip, pinned by SHA-256.
Licensed under the GNU LGPL 2.1 — https://github.com/MacPaw/XADMaster

### Microsoft Edge WebView2 Runtime
Only fetched from Microsoft (https://go.microsoft.com/fwlink/p/?LinkId=2124703) when it is missing,
and only run after its Authenticode signature is verified as Microsoft's.

### The screensavers themselves
Downloaded from the Internet Archive's Wayback Machine copies of the official Doraemon websites
(dora-world.com, dora-movie.com, dora2006.com, doraeiga.com). This project contains none of them.
